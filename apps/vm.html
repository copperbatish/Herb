Firefox

Runs in your browser

A full copy of the Firefox engine, running inside this tab and browsing through Herb’s proxy server.

Heads up: about 50 MB downloads the first time, and it needs plenty of memory (several GB of RAM). Only 3 people can run Firefox at once, for 20 minutes each – if it’s full you’ll wait in line and can use the Firefox-style browser meanwhile.
Compatibility mode: this device can’t run the full Firefox engine (Safari on iPhone and iPad doesn’t support what it needs). So Open Firefox will start a Firefox-style browser that works here instead, and it browses through Herb’s proxy.
