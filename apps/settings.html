Proxy

Herb checks every server when it starts and automatically uses the fastest one that works.

Checking…

Reset proxy
If a site or the GeForce NOW sign-in looks broken after an update (common in the iPad home-screen app), this clears the proxy’s saved background worker and reloads Herb. Your accounts and settings are kept.
Proxy engine
Scramjet is the default for the Web Browser, Movies and Cloud Games. Ultraviolet is the older engine, handy if a site doesn’t work with Scramjet. Applies the next time a page opens.
Connection engine
libcurl is best for live sites (WebSockets, cloud games). Epoxy is the older fallback. Applies after you reload the browser app.

Getting started

What is Herb?

A desktop in your browser: a web browser that goes through Herb’s proxy, games, Movies, Copperchat, Herb AI, cloud gaming and more. Nothing to install.

How do I add Herb to my iPad or phone home screen?

Open Herb in Safari, tap Share → Add to Home Screen. It then opens full-screen like an app. GeForce NOW and Xbox can be added the same way from their own pages (Games → Cloud).

What are herb:// addresses?

In Standard proxy mode every Herb app opens as a browser tab with its own address: herb://games, herb://settings, herb://movies, herb://ai and so on. You can type them in the address bar, and bookmark them.

How do bookmarks work?

Tap the star at the right of the address bar to save the page; tap it again to remove it. Bookmarks show on the new-tab page and are stored on this device.

How do I make Herb’s tab look like another site?

Settings → Privacy → Tab disguise. Pick Coursera, Google Classroom, Docs and more, or Custom to type your own title and icon. It changes the tab title and icon only.

Which layout should I use?

Settings → Interface. Desktop has windows and a taskbar, Standard proxy is one full-window app with a top bar, and iPadOS style is a home screen with a dock. Changing it reloads Herb.

Proxy & websites

A website won’t load or looks broken.

1) Press reload in the Web Browser. 2) Try the other engine: Settings → Proxy → Proxy engine (Scramjet is the default, Ultraviolet is the older one). 3) Settings → Proxy → Reset proxy, then reopen the app.

It says no proxy server is reachable.

Your network may be blocking Herb’s servers. Settings → Proxy → Re-check. If one server shows as working, pick it there. Some school or work Wi-Fi blocks everything except certain addresses; try a different network to confirm.

Herb feels slow or the ping is high.

Herb checks every server each minute and uses the fastest. The ping number in the corner is the time to reach the proxy server, so it depends mostly on your connection. Close other tabs that stream video, and avoid pinning a slow server in Settings → Proxy.

I see an old version after an update.

The proxy worker is cached. Settings → Proxy → Reset proxy. In the iPad home-screen app, also swipe the app closed and reopen it.

I see a blank box or white square where a page should be.

Scramjet couldn’t start in this browser. Reload once; if it stays, switch Settings → Proxy → Proxy engine to Ultraviolet. Clearing Herb’s website data (Safari settings → Advanced → Website Data) also fixes a stuck worker.

Why can’t I log in to some sites?

Sites with strict bot checks (Google sign-in, some banks) may refuse proxied logins. Try the other proxy engine. Never enter passwords you care about on a network you don’t trust.

Video

YouTube says “This video is unavailable”.

YouTube blocks the cloud server Herb’s proxy runs on, so videos refuse to play. Pages and comments load, but the video itself can’t. Other video sites (TikTok, Vimeo, Twitch and normal MP4/HLS streams) do work.

Movies only shows trailers / trailers won’t play.

Movies uses TMDB for the catalogue and YouTube for trailers, so trailers hit the same YouTube block. Full movies are not offered.

Netflix, Hulu or other streaming services won’t play.

They load and you can sign in, but many of them block cloud-server addresses and require DRM that may not work through a proxy. Herb can’t get around that.

Cloud gaming

GeForce NOW or Xbox won’t sign in.

Open Herb from the same address the cloud page uses (Safari blocks sign-ins in embedded pages from another address). If it’s still stuck, Settings → Proxy → Reset proxy and try again. A home-screen app keeps its own sign-in, so you sign in once inside it.

“The game quit unexpectedly” or the stream stays black.

Game video goes directly between you and the game servers over UDP; the proxy can’t carry it. If your network blocks that traffic (common on school Wi-Fi), the stream can’t start. Try another network or a phone hotspot.

There’s a blurry bar over the clock and battery.

Remove the cloud app from your home screen and add it again; the new version uses a solid black status bar.

Games

A game won’t load or stays black.

Reload the window. Big games take a while the first time. If it’s still blank, the game file may be temporarily unavailable; try again later.

Is my game progress saved?

Most games save in your browser on this device. Clearing website data, using private browsing or another device starts fresh.

Appearance

My custom wallpaper doesn’t show.

Settings → Desktop → Wallpaper → Image, then choose a picture. It’s stored at full quality on this device only, so each device needs its own. Very large photos (50 MP+) may be too big for iPad memory; use a screenshot-sized image if it fails.

How do I get the colorful icons back?

Settings → Appearance → Icon style → Colorful.

Everything is too bright / too dark.

Pick a different theme or accent color in Settings → Appearance, or turn off Glass blur and Fireflies for a flatter look.

Privacy & account

What is the about:blank cloak and panic key?

Settings → Privacy. The cloak reopens Herb inside an about:blank tab so the address bar shows nothing; turn on Launch in about:blank to do it every time Herb opens. The panic key instantly jumps to your panic URL.

What does Herb store?

Settings, wallpaper and game saves stay in your browser on this device. Signing in syncs your account data (for example Copperchat and app store items) through Herb’s database.

How do I reset everything?

Settings → About → Reset all settings. To also clear game saves and sign-ins, clear Herb’s website data in your browser settings.
